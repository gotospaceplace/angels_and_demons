# Angels and Demons — Project Documentation

Working game concept and planning pack for Claude Code. Start with `01_DESIGN_OVERVIEW.md`, then read documents 02–05. Treat all documents as version 0.1; unresolved decisions are intentional. Do not begin implementation before Phase 0 approval.

## Phase approval

Each phase concludes with a `PHASE_X_SIGNOFF.md` committed to the repository. The sign-off file contains: date, gate criteria status, accepted deviations with rationale, and conditions carried forward. Committing the file constitutes approval. See `05_DEVELOPMENT_ROADMAP.md` for gate criteria per phase.
